# Web Development Lab – Practical Work

## About the Project
This repository contains my Web Development Lab practicals from P1 to P13. These practicals helped me understand HTML, CSS, Flexbox, CSS Grid, Git and GitHub.

## Practical List

### P1 – Project Folder and Terminal Navigation
Created project folders and learned basic terminal commands such as `mkdir`, `cd`, `pwd` and `ls`.

### P2 – Portfolio Repository with Initial Commit
Created a portfolio project and learned how to initialize a Git repository and make the first commit.

### P3 – Feature Branch Git Workflow
Practiced creating a feature branch, making changes, committing them and merging the branch into main.

### P4 – GitHub README and Version Tags
Learned how to create a README file and manage project versions using Git tags.

### P5 – Semantic Bio Page
Created a bio page using semantic HTML elements to organize webpage content.

### P6 – Full Portfolio Page Structure
Created a complete portfolio webpage structure using HTML and CSS.

### P7 – Design Tokens and Typography System
Used CSS variables to create a consistent typography system with font sizes, colors and spacing.

### P8 – Sticky Navbar and Card Overlay
Created a sticky navigation bar and image cards with overlay content using CSS.

### P9 – Responsive Navbar and Card Grid using Flexbox
Designed a responsive navigation bar and card layout using CSS Flexbox.

### P10 – Portfolio Header and Footer with Advanced Flexbox
Created a portfolio header and footer using advanced Flexbox properties.

### P11 – Newspaper-style Three-column Layout with CSS Grid
Designed a newspaper-style webpage with three columns using CSS Grid.

### P12 – Portfolio Projects Grid with Advanced CSS Grid
Created a portfolio projects section using advanced CSS Grid properties.

### P13 – Choosing between Flexbox and Grid for a Shared Layout
Practiced using Flexbox and CSS Grid together to create an organized webpage layout.
